# Digit Classification Using MLP

## 📌 Project Description
This project classifies handwritten digits (0–9) using a Multi-Layer Perceptron (MLP) neural network.

The model is trained using the MNIST handwritten digit dataset and can predict digits drawn by the user through a simple GUI.

## 🧠 Algorithm Used
- Multi-Layer Perceptron (MLP)
- Supervised Machine Learning
- Neural Network Classification

## 🛠️ Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Tkinter
- Joblib

## 📁 Project Files

| File | Description |
|---|---|
| `train_model.py` | Trains the MLP model |
| `gui.py` | Provides the GUI for drawing and predicting digits |
| `requirements.txt` | Contains required Python libraries |
| `digit_model.pkl` | Trained MLP model |
| `confusion_matrix.png` | Model evaluation result |
| `gui_prediction_2.png` | GUI prediction screenshot |
| `gui_prediction_4.png` | GUI prediction screenshot |

## 📊 Model Performance
The MLP model achieved approximately **96% accuracy** on the test data.
